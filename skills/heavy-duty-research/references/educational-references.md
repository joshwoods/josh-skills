# Educational Reference Pack

Use this file as the router for local research-method references. Do not give the user a bare list of links when this skill is asked to teach or justify research method. Load the relevant local note, summarize the concept, and apply it to the user's topic.

These notes are method scaffolding. They should not become the main evidence base for ordinary topical research. In most research briefs, use them internally to make the work better, then cite domain-specific sources in the answer.

Prioritize concepts over named frameworks. The named sources are examples and validation anchors, not the object of the skill.

## Concept Coverage

The local notes teach these transferable concepts. The named sources are examples that ground the concepts:

- Source-role matching: decide whether a source is evidence, context, a primary artifact, a lead, or an example.
- Context recovery: identify who created a source, why, for whom, with what evidence, and under what incentives.
- Claim tracing: follow claims, numbers, quotes, and media back to original records.
- Literature graph navigation: move backward through references, forward through citations, and sideways through related work.
- Reading-depth control: triage sources before deep-reading them.
- Search transparency: record where and how evidence was sought.
- Structured synthesis: group evidence by claim, method, population, time, jurisdiction, and source type.
- Confidence calibration: state what the evidence can support, why it may be wrong, and what would change the conclusion.

## Reading Order

1. Start with `research-concepts.md` when the user wants to learn the methodology or when deciding which method applies.
2. For basic web research hygiene, read `source-evaluation.md`.
3. For academic or technical research, read `literature-discovery.md`.
4. For high-stakes synthesis, read `evidence-synthesis.md`.
5. For broad heavy-duty research, read only the concept and example notes needed for the current risk.

## Output Guardrail

- Do not put these method references in the evidence table unless the research topic is research methods, education, evidence synthesis, source evaluation, or literature review.
- Do not make the final answer read like a lesson on named frameworks unless the user asks for those frameworks.
- Do use the notes to shape the search log, source appraisal, confidence labels, and unknowns.
- Prefer topic-specific educational references in the final "Educational References" section.
- Mention a method source briefly only when it explains a visible methodological choice, such as why a finding was downgraded for indirectness or why a social post was treated as a lead rather than evidence.

## Teaching Patterns

- Beginner: explain source roles, creator/incentive context, purpose, and cross-checking.
- Intermediate: teach literature discovery, citation chasing, source triage, and evidence tables.
- Advanced: teach protocol/scope, inclusion/exclusion, screening transparency, bias assessment, and confidence grading.

## Mini Exercises

- Source triage: rank five sources on one claim as primary, strong secondary, weak secondary, lead only, or unusable.
- Claim tracing: pick one claim from a secondary article and trace it to the original paper, filing, dataset, statute, transcript, or repository.
- Paper pass: first-pass five papers and produce a keep/maybe/reject table with reasons.
- Evidence table: convert ten sources into source type, date, method/data, claim used, limitation, and use in synthesis.
- Counterargument pass: write the strongest credible case against the current conclusion.
- Confidence pass: assign high/medium/low confidence to each finding and state the downgrade reasons.
